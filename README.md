# Android-Search-for-Files-with-Local-AI-model
Find files easily on Android
<br><br>
### Requirements:
<br><br>
Termux (App)<br>
pkg install python<br>
pip install litert-lm-api
<br><br>
### Edit the search.py file (1 line)
<br><br>
You must change the line to match the path/name of your local AI model. (Line 21)
<br><br>
### Usage:
<br><br>
python search.py
<br><br>
### Notes:
<br><br>
Try not to use words like: ago, keyword, old, etc.. if you do, or you see a word has been added to "keywords" simply dont use it, and rephrase the question without that word.
