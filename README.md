# Android-Search-for-Files-with-Local-AI-model
Find files easily on Android
<br><br>
### Requirements:
<br><br>
pkg install python<br>
pip install litert-lm-api

<br><br>
You must change the line to match the path/name of your local AI model. (Line 21)
<br><br>
### Usage:
<br><br>
python Search.py Find all photos from the last year
